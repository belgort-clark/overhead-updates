# Overhead updates

Sparkle update feed and archives for [Overhead](https://belgort-clark.github.io/overhead/), a native macOS app that shows the aircraft flying near your home.

- **Download:** [Overhead.dmg](https://github.com/belgort-clark/overhead-updates/releases/download/updates/Overhead.dmg)
- **Website:** https://belgort-clark.github.io/overhead/
- **Release history:** [CHANGELOG.md](CHANGELOG.md)

The appcast lives at `appcast.xml`; update archives are attached to the rolling `updates` release.
